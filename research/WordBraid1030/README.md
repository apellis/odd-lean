# Inner vacuum-word crossing transport (partial)

These standalone Lean sources establish transport of an independently induced inner crossing through the whole-word reverse Hom coordinates, including arbitrary reservoir morphisms, total parity and explicit common-content transport. The consumer also applies the result to an actual inner-then-outer two-crossing composite.

They do **not** prove the corrected three-crossing mixed braid, its original three-dot polynomial correction, extension from word modules to arbitrary modules, or nondegeneracy. They are retained as a partial mathematical checkpoint, outside the package root/import inventory.

The original standalone versions were checked with strict-default importing consumers and an ownership-based standard-axiom audit. This preserved copy has not received package integration CI or independent source review. The files retain their original standalone module names: the consumer imports `WordBraid1030Checked`, and the audit imports `WordBraid1030Consumer`.
