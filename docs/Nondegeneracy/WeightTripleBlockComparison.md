# Triple comparisons at a common second predecessor

For the multicolour part of Brundan--Ellis (1.9), two orders of the first
pair share the same stored second block and final output. Their successor
constructors need not be syntactically identical.

`elvWeightTripleComparison_pairBlock` retains that common block explicitly
and factors the already selected triple chart through the already
selected weight-pair chart. Its `_hom` theorem gives the native module
component. `elvEFunctor_comp₃_pairBlock` retains outer dispatch as a whole
functor equality, using the literal content induction to the specified
output. The support witnesses and content equalities remain explicit;
no module is replaced by an independently normalized intermediate model.

The producer and concrete consumer pass scoped strict checks and an
all-owned axiom audit. The consumer uses both first-pair word orders at
the same actual second block and output, all Bool colour triples, both
moving parities and the regular product-vacuum module. In particular,
the swapped order uses the proved `blockSucc₂_swap` witness rather than
a reflexive surrogate. This is the common-block chart used by the
multicolour crossing comparisons.
