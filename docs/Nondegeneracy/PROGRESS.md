# Odd nondegeneracy: progress entrypoint

Branch scope: **Phase 1** is symmetrizable data with homogeneous parameters;
**Phase 2** pursues inhomogeneous parameters for symmetrizable data.
Nonsymmetrizable data are not pursued. Completion means matching the most
general cited even theorem through a checked all-even specialization, with
2 invertible in the base ring. See [FieldScopeBoundary](FieldScopeBoundary.md).

[STATUS.md](STATUS.md) is the single current status board: scope, established
reductions, concrete inputs, remaining obligations and verification evidence.
[HANDOFF.md](HANDOFF.md) gives readiness, dependencies and next targets.
[SwappedNondegeneracy.md](SwappedNondegeneracy.md) is the proposed written proof.

The Phase 1 odd/mixed theorem remains open in Lean. Historical checkpoint
narratives are available in git history; this file does not duplicate them.
