# Coefficients in the original-weight path chart

`SupportedSectors.tensorPathCoefficient_square` identifies the direct
raw `SYM D k` coefficient action under the actual
`tensorPathValueChart`. Its target is the existing signed
`wordFamilyArrow` of the original `coefficientEndomorphism`, at the
original formal-content weight and reversed path label.
`tensorPathCoefficient_square_apply` applies the same whole-family
identity to every actual output vector and content block.

The proof transports the global word-chart square through four existing
whole-data comparisons: the path endpoint weight, the entire path Hom,
the direct versus recursive coefficient action, and the actual path
versus global word chart. A generic indexed-category transfer keeps
these equalities together. It does not replace the original input
object or evaluate on an assumed cyclic presentation.

The consumer uses a two-odd datum with a genuine root-weight collision.
Its nonempty two-letter original-weight path has a nonzero vector whose
quotient coordinate contains both odd colours. The consumer applies the
vector square to this occupied vector and a mixed-parity source
coefficient, and the family square to arbitrary upward paths. This supplies the target-action square needed when the
canonical row observation is evaluated at its prescribed source unit.
Transport from a coefficient acting on the supported matrix row through
`tensorRowTargetIso` remains a separate original-row naturality step.
No matrix-observation equivariance or generator injectivity theorem is
asserted by this path-chart result alone.
