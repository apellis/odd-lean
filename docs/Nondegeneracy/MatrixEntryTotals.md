# Actual shifted matrix entry totals

Brundan--Ellis (1.13)--(1.14) and DeformedMatrixComparison section 4 use
the ordinary unit/counit and induction-dot maps, composed with canonical
parity isomorphisms. ELVMatrixEntryTotals identifies these actual module
maps with their component formulas.

moduleUnitColumn_total is the ordinary dot power after the actual
adjunction unit. moduleCapRow_total is the actual adjunction counit after
the ordinary dot power. moduleUnitColumn_upper identifies the unit column
in canonical upper-Hom coordinates with inductionUnitDotColumn, and
unitMatrixEntry_some_upper retains exactly the canonical source parity
coordinate. capMatrixEntry_some_total cancels the canonical target parity
coordinate and gives the ordinary cap row.

These statements hold for all moving colours and arbitrary old
supermodules where applicable, over the supplied commutative ring.
unitMatrixEntry_none records the literal module-map definition of the
first slot. No evaluation of that mate component as the signed balanced
crossing, and no finite matrix inverse, is assumed or asserted here.

uses both moving parities, distinct endpoint orders, positive cutoffs,
all ordinary dot powers, and every shifted unit/cap slot in a three-slot
family. All nine owned declarations pass its axiom audit. Full CI and the
