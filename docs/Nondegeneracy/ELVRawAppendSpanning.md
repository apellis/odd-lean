# Finite append ranges before coefficient truncation

`ELVRawAppendSpanning.lean` proves the concrete finite supremum of ranges of smaller full old Hom spaces is the full untruncated old cyclotomic Hom. It uses the existing monic endpoint, crossing skeletons, and tail normalization; only the actual old ideal is imposed. Both source and rational odd-colour consumer passed full CI at97bc63ca43c98892a42ab392595323d86b023ce0.

The full old coefficient algebra need not be finite-dimensional over k. Ordinary scalar specialization, compatibility with append maps, and induction from the scalar vacuum are needed for an ordinary probe finite-dimensionality theorem. The direct-unit route may remove that theorem as an invertibility prerequisite, while leaving this raw spanning result useful independently.
