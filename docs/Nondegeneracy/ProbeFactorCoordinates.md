# Probe cup coordinates

Brundan–Ellis, *Super Kac–Moody 2-categories*, Definition 1.5,
(1.13)–(1.14), requires the central probe matrix entries in the prescribed
factor adjunction coordinates.

`ProbeReservoir.probeCupFactorIso` compares the full two-probe cup-path
object with `homContentPreF.obj (homContentPreE.obj Z)`. Both functors use
the same weight equation `muP_preF` and the canonical inverse-defined
left adjunction of the probe factor. The comparison composes the path
endpoint isomorphism, the computed inner-strand equality transport and
the return-path transport. It makes no assumption about a central inverse
or a crossing coefficient.

The paired consumer uses the constructed positive-level ELV family on
both sides, connected asymmetric parameters and both odd colours. Its
mixed sector carries an explicitly nonzero two-odd PBW coordinate in the
input of the full identity Hom object. The owned declaration audit checks
the cup-chart module.

The cup chart supplies a coordinate isomorphism; the principal crossing
comparison and the augmented central inverse remain separate results.
