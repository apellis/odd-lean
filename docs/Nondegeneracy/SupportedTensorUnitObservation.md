the actual supported matrix module. It applies `tensorOriginalWordEntry`,
evaluates the resulting whole arrow at the regular probe and the fixed
source-word block, and applies the global target path chart. Finally it
uses `PowerWordQuotientCoordinates.coordinate` to return the literal
source quotient class. No layer decomposition, generator comparison or
regular-probe faithfulness premise enters its definition.

`TensorVacuumWords.chart` back to the original reservoir weight, using
only `TensorReservoirWords.path_weight` and the equality of the whole path
and word functors. `tensorSourceWordBlock` is the block of the specified
source word, whose labelled colours are recovered by
`tensorSourceLabels_colors`. The source unit is the literal old-word unit
pulled back through that global source path chart and
`tensorOriginalRowSourceIso`; the source functor is unchanged.
