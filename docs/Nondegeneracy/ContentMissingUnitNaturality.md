# Input naturality of the old missing-colour inverse rows

The even prescribed finite unit columns form an ordinary natural matrix
on all input module maps. `unitColumnInputNatIso` assembles their constructed
component inverses; projection followed by the original parity unshift
proves `unitColumnInverseRow_supernatural`.

`contentMissingUnitRow_supernatural` supplies the constructed old
missing-colour module inverse, without an inverse-naturality assumption.
`contentMissingUnitRowTransformation` retains the exact inverse row on
input evaluation. The consumer uses a nonzero odd canonical parity
comparison on a full old representable, both moving parities, even input
identities, and the explicit minus for the odd top row on odd input.

This signed family is the input required to assemble the finite dotted-unit
boundary coefficients in the existing Rouquier construction. It changes
neither the ordinary forward columns nor the normalized left-counit
convention.
