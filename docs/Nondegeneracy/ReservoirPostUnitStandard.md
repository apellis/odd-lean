# The post-unit in native append coordinates

This continues the actual post-unit chart for SwappedActionAssembly F2.
`reservoirPostCup_canonical` evaluates `homContentPostCup`, removes its
prescribed shift, selects its whole-weight output block, and removes the
stored successor content using the specified content equality.

The result is the canonical content-append adjunction unit followed by
the power of its raw restricted dot. The source Hom object, source
module, block, Hom content shift, and exponent remain arbitrary. The
proof uses the already checked actual post-cup chart and then substitutes
the successor content in the literal append functor. No unit or dot
compatibility assumption is introduced.

The paired consumer retains both odd colours of the asymmetric fixture,
arbitrary source families and every exponent, a nonzero Hom shift, and
an occupied odd coefficient module with nonzero first unit column.
