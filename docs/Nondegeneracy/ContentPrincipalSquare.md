# Whole principal mate square on canonical content

For Brundan–Ellis (1.13)–(1.14), `ELVContentPrincipalSquare`
compares the prescribed negative-crossing mate through the chosen lower
E/F source chart and upper F/E target chart as a whole module morphism.
The input content is `β + [i]`; the module and truncation bound are
arbitrary. The theorem statement retains the given crossing family and
its selected module charts.

The comparison uses the previously checked raw principal square,
fully faithful content extension, and the strict append/inclusion
squares. A generic complete-square kernel binds the source and target
module factories before the concrete content categories are substituted.
It introduces no inverse or compatibility hypothesis in the specialized
content theorem. The checked ordinary-to-native source linear-map equality
is applied before evaluating the raw square, so both final evaluations
retain the same native coefficient profile.

The producer and paired concrete consumer pass strict scoped checks at
the default proof budgets. Every owned declaration passes the axiom
audit. The consumer uses both colour parities, parity-shifted
representable input modules, arbitrary bounds, and the zero bound.
The supported local inverse transport can now use this whole principal
square together with the checked unit-column and cap-row squares. The
missing-predecessor case is handled separately and does not assert that
F/E vanishes.
