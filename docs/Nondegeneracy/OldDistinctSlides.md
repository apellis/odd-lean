errors and both compatibility settings. All six owned declarations pass
the axiom allowlist. The consumer tests connected mixed and two-odd data,
empty and mixed contexts, representable action on every input vector and

remains separate. The source equations must next be passed through

coordinates; these coefficient identities alone are not the global probe
