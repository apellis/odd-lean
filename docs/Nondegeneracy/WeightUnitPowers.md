# Selected weight unit columns

`elvWeightUnit_dotPower_comparison` identifies the selected weight unit followed by every ordinary power of the selected upper dot component with the ordinary content unit/dot column, through the selected successor coordinate. It applies at every output block, without requiring that block to have a lower predecessor.

`elvWeightDotPower_total_component` identifies the literal selected `SKM.rouquierPower` total component with the ordinary power of the selected dot component. `elvWeightUnitPower_total_comparison` therefore compares the prescribed weight unit/Rouquier-power field itself with the ordinary content unit/dot column. Every power, arbitrary input modules and both moving parities are retained. These are supporting comparisons for BE (1.14); using a constructed finite matrix inverse remains separate.

The producer and paired concrete consumer pass scoped strict checking, including the owned-declaration axiom audit. The consumer includes empty and singleton output contents, arbitrary dot powers and parity-shifted truncated ELV representables. Full integration CI remains required.
