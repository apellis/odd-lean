# Weighted matrix inverses on canonical content modules

Brundan–Ellis (1.13)–(1.14) specify finite matrices of module maps. The
weighted row and column entries assemble into
`weightedUnitMatrixModuleMap` and `weightedCapMatrixModuleMap`. Their total
components are exactly the prescribed weighted forward matrices, and the
assemblies are even module maps.

Restricting the output category to the literal full multiset-content
subcategory makes the height and the required matrix size constant.
`weightedContentUnitMatrixMap_bijective` and its cap counterpart apply the
established inverses of the prescribed forward components to every word
of that content. `weightedContentUnitMatrixIso` at nonnegative height and
`weightedContentCapMatrixIso` at nonpositive height therefore invert those
specified module maps. No inverse family or compatibility premise is
supplied. Both inverse identities retain the given forward map, and the
inverses are even. The `_hom_total` equations identify their forward
components with the given weighted matrices.

The paired consumer uses the connected two-colour truncated representable
modules, both parities, positive sizes eight and ten, negative size one,
height zero in both directions, and the vacuum. Every owned declaration
is audited against the standard three-axiom allowlist.

This establishes output-module naturality on the canonical content block.
Naturality of these matrix inverses in an arbitrary input module is a
separate assembly step.
