# Full-ELV dot at original weights

Status: proposed source, pending CI; depends on ELVWeightModules.

elvContentDotTo uses the exact existing contentInductionTransform definition
of contentInductionDot, at a chosen common target. elvContentDotTo_heq records
that identification, retaining the entire balanced-coend parity twist and
normalization. elvWeightDot assembles these dots on the actual existing
weight product, using zero on blocks without predecessors.

The component nilpotence theorem is quantified separately at each actual
content block of the target weight. Its exponent can depend on that block;
no global weight-fibre nilpotence is asserted. The asymmetric all-odd consumer
uses the actual vacuum module product and a nonempty successor block.

Denominator product assembly is tracked separately in
SeparatedDenominatorInputs.md. Actual reservoir-denominator specialization
and multicolour action assembly remain open.
