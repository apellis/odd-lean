# Same-colour weight crossing squares

Brundan--Ellis (1.9), as used in DeformedActionAssembly §6, requires the
prescribed same-colour crossing to have square zero.

`contentInductionTransform_square_total_to` retains the specified common
output content in the existing induction relation.
`elvWeightCrossVia_square_total` transports it through the selected weight
pair comparison, cancelling the intermediate comparison.
`elvWeightCrossComponent_square_total` gives square zero for the actual
global crossing component at every original weight, module, output block
and word. At an absent double predecessor the given component is zero;
no support or nonvanishing hypothesis is added.

The strict producer and paired consumer pass, and all three owned
declarations have standard axioms only. The consumer uses both repeated
parities at actual supported two-step outputs and a false-colour crossing
at a true-colour output with no false predecessor.

Assembly of these component equations into the native two-morphism square
field, the triple relations and the complete factor family remain next.
