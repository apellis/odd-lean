# Coefficients at the canonical original-row unit

`tensorOriginalWordCoefficient_observation` applies the full raw source
coefficient action to the actual pulled-back row Hom, then evaluates it
at the prescribed `tensorOriginalSourceUnit`, through the actual
original-weight `tensorPathValueChart` and quotient coordinate. The
result is the same original signed coefficient arrow on the charted
row value. The source and target row objects, content block, cyclic
word object and unit are precisely those in
`tensorMatrixQuotientObservation`.

The coefficient on the entire original-row Hom is the existing
`pathHomCoefficientAction`, so it is literal chronological
postcomposition and retains source multiplication order. Its value on
the source unit follows from `tensorPathCoefficient_square_apply` and
functorial evaluation of composition. No homogeneous-coefficient or
homogeneous-row hypothesis is imposed.

The consumer applies the theorem to the actual nonzero two-letter
matrix vacuum for the two-odd root-collision datum, with a mixed-parity
source coefficient. This is the coefficient square on the original
whole-row Hom. Identifying it with the separately defined supported
matrix-module coefficient action still requires the
`tensorRowTargetIso` naturality square and the corresponding row
pullback statement; that stronger equivariance is not asserted here.
