# The chosen dotted rows at stored representatives

In Brundan–Ellis (1.13)–(1.14), the finite inverse uses ordered powers of
the selected dot composed with the selected unit or counit. For any
stored-target append edge, `probeAppendToCapRow` and
`probeAppendToUnitColumn` are exactly those fields on evaluated modules.
No alternative bending maps or powers are introduced.

`probeAppendToCapRow_app` and `probeAppendToUnitColumn_app` identify every
homogeneous component with the corresponding OLD field, for every power
index. `oldAppendToCapRow_eq` and `oldAppendToUnitColumn_eq` identify the
latter transformations with the ordinary `capDotRow` and `unitDotColumn`
fields used by the reindexing compatibility squares. These comparisons
retain the original right-adjunction unit and counit.

The consumer applies the component formulas and the ordinary-field
comparisons for both colour parities, all power indices and both
homogeneous components, using reordered mixed-content regular probes.
It also checks the selected unit column on an odd input map. These are
field comparisons; the finite inverse identities come from the separately
constructed local records and their coordinate transport.
