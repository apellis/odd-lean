# Post-side mixed-mate denominator units

The whole weight fibre need not have a common nilpotence exponent. The mixed-mate argument only needs two explicit source polynomials to be units.

For even dots x and y, write X,Y for the existing target dots and A,B for their literal source dots (B uses the right transpose of y). For a crossing Φ commuting with Y and its target transpose, the existing monomial transport gives

  Dot((X−Y)² ≫ Φ) = (A−B)² ≫ Dot(Φ),
  Dot(c Xⁿ + d Y) = (c Aⁿ + d B) ≫ U.

Thus (X−Y)² ≫ Φ = c Xⁿ+d Y and units of (A−B)² and c Aⁿ+d B suffice for invertibility of Dot(Φ). This does not assume whole-fibre nilpotence, an integer grading, or invertibility of the desired dotted mate.
