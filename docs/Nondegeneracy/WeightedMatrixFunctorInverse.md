# Prescribed weighted matrix inverses natural in input modules

The weighted finite coordinate maps assemble the specified parity-shifted
families in Brundan–Ellis (1.13)–(1.14). `weightedUnitMatrixSourceFunctor`
and `weightedCapMatrixTargetFunctor` preserve addition, scalar action,
and both map parities. `weightedUnitMatrixModuleNatTrans` and
`weightedCapMatrixModuleNatTrans` have exactly the previously inverted
prescribed module matrices as their components.

On a literal multiset output block, the established module inverses
assemble into `weightedContentUnitMatrixFunctorNatIso` at nonnegative
height and `weightedContentCapMatrixFunctorNatIso` at nonpositive height.
Their naturality uses the given whole matrix transformations; it imposes
no condition on the input-module map. Both directions have even module
components. The `_hom_total` equations retain the prescribed weighted
forward matrices at every output word.

The paired consumer tests both parities and every finite matrix size,
odd canonical input-module maps in both directions, positive counts
eight and ten, negative count one, both height-zero isomorphisms, and the
vacuum. Every producer declaration is audited against the standard
three-axiom allowlist.

These isomorphisms concern arbitrary global weighted input modules with
output restricted to the canonical content block. Identifying their
endpoints with a chosen content-action realization remains a separate
restriction/extension comparison.
